KeePassDX MO

Personal fork of KeePassDX with more robust Google Drive sync. Installs next to the official app.

Install for Android All releases

First-time install

Since this is side-loaded (not from Google Play), Android will ask you to allow install from your browser or file manager the first time. Open Settings → Apps → Special app access → Install unknown apps and enable it for the app you're downloading with.

Tap the button above on your Android device, then open the downloaded KeePassDX-MO-release.apk.

Updates

New releases are published to the Releases page. The link above always points to the latest. Obtainium can track this repository too.
